# Adjacent Memory Systems

_Status: Informative_

Memory and retrieval engines answer how to extract, organize, retrieve, and use context effectively. SMP is intended to compose with those systems by defining portable custody and verification properties.

A system may preserve immutable evidence, derive temporal beliefs, rebuild indexes, and provide excellent retrieval while still needing portable contracts for authority-at-write, transfer acceptance, erasure scope, provider exit, and stale-restore detection. Conversely, custody conformance does not imply high recall or answer quality.

Adjacent categories include:

- memory and retrieval engines;
- temporal and graph memory systems;
- local-first knowledge systems;
- model- or product-managed memory;
- evidence and transparency systems;
- export, packaging, and interchange formats.

These are composition surfaces, not competitors ranked by this repository. Informative references and comparisons must avoid novelty, benchmark, or completeness claims unless independently supported.
