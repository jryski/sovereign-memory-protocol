# Open Questions

Current unresolved protocol decisions include:

- exact logical versus encoding-profile boundary;
- canonical base encoding and golden-vector process;
- event, stream-registry, checkpoint, and receipt envelopes;
- delegation and compromise semantics;
- bilateral transfer state machine;
- erasure receipt privacy and closure criteria;
- source-qualified completeness and freshness;
- verifier resource ceilings and stable result registry;
- profile/version evolution and deprecation;
- self-declaration versus independent conformance review;
- public license and publication governance.

Open questions are proposals, not permission to weaken accepted custody requirements.
