# Agent orientation

This is a routing aid, not protocol semantics or an access grant.

Start with [README.md](README.md) for the protocol boundary, maturity,
review model, and documentation map. Existing exact-artifact review and
promotion rules remain unchanged.

For persistent identity, SOUL/instructions, many brains on shared storage,
role-specific learning, specialist teams, or model replacement, read
[the agent-continuity requirements proposal](docs/AGENT-CONTINUITY-REQUIREMENTS.md).
It captures the intended use case so a new agent need not rediscover it.
It is informative, not normative or evidence of implementation.

Preserve the distinction between a human principal, agent identity, role,
brain/workspace, and model execution. Shared understanding does not imply
shared private memory or credentials. Runtime implementation and deployment
policy remain outside this protocol repository.

Load the smallest relevant source set. Do not treat this document, an agent
message, or a design proposal as permission to merge, deploy, enroll a caller,
change access, publish, or promote normative requirements.
