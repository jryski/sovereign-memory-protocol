# SMP status checkpoint

Updated September 7, 2026.

SMP is public and remains a protocol draft. It defines implementation-neutral custody, provenance and authority semantics; Household OS, Core, User MCP and worker systems remain separate implementations or consumers.

Draft PR 13 at `c7587cfdf2ddf253dc673a176191d804ef8ea0b5` passed 24 local tests, package validation over 41 files and CI before this documentation-only checkpoint. That evidence applies to that exact earlier candidate. It is not independent review, a release, or a conformance claim for deployed applications.

Private-identifier checks use optional external policy rather than shipping private identifiers in the public checker. Missing policy must be reported as not performed. Public availability does not remove the boundary around private operational records.

Current downstream lesson: incomplete store coverage must not become a claim of global absence. Any normative change requires explicit protocol review; this checkpoint changes no normative semantics, license or release state.
